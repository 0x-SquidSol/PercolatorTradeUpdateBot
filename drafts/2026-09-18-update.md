# Percolator update — 2026-09-18

> Draft X thread — review, edit, then post manually. Generated by dcc-watch.

## Thread

1/ Big shipping cycle: ~100 merged changes across the engine and the on-chain program. 🚀 The headline — a full end-to-end security review of everything since the live build, with every issue it found already fixed and re-tested.

2/ Security: a trader paying a fraction short of their trading fee was treated exactly like one who paid in full — the remainder was collected from no one, quietly shortchanging the protocol, LPs, creators and the insurance pool. Now the shortfall is always charged.

3/ Safety: we found paths where a tiny rounding leftover could permanently freeze withdrawals for an entire group of accounts, and where expired collateral could still be counted as good backing. Both closed, each with its own dedicated regression test suite.

4/ Reliability: a long list of "stuck account" cases — positions that only the owner could unblock, or that no one could — are now advanceable by any keeper. Fewer dead ends, more ways for the network to heal itself without admin intervention.

5/ Proof work: our machine-checked proof suite now stands at 331 properties, all green. One test showed the value clearly — a rarely hit trade path could be wired backwards and 293 existing tests still passed. It now has a test that catches it. 🔬

6/ On the program side: fees can no longer move between the moment you sign and the moment your trade lands — callers now declare a cap and anything above it is rejected. Closed market addresses are also permanently marked so they can't be recycled.

7/ Where things stand: all of this is merged, reviewed and formally verified. It is not live yet — the main network still runs the previous build, and these roll out after the final deployment checks. Steady, careful, shipping.
