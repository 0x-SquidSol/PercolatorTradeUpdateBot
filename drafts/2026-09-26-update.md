# Percolator update — 2026-09-26

> Draft X thread — review, edit, then post manually. Generated by dcc-watch.

## Thread

1/ Big cycle for the Percolator app: 30+ fixes landed, and a wallet-login upgrade cut our high-severity security findings from 27 to 13 — without a single shortcut or suppression. 🚀

2/ Security: our wallet sign-in library was several versions behind, which carried known vulnerabilities. We upgraded it end-to-end and re-ran the audit: total findings dropped from 57 to 34, high-severity more than halved. Fewer ways in, same smooth login.

3/ Risk clarity: if we had no liquidation signal for a position, the screen could quietly read as "safe." Now a missing signal is shown as unknown, and we display margin health wherever a liquidation price isn't available. Traders see their real risk, not a comforting blank.

4/ Reliability: a handful of ways the app could fail you are gone — trades blocked by a fee value that never got passed through, deposits that silently dropped, balances that flickered, and failures when a busy node returned a stale response. The app now retries instead of giving up.

5/ Honesty in numbers: charts no longer turn a row with no price into a candle, stats no longer report an unrecorded fee as zero or a partial volume as complete, and we stopped implying every market charges the same trading fee. We also now show exactly where each fee goes. 📊

6/ Where things stand: the app fixes are merged, reviewed and backed by a dozen new automated test suites. Separately, a full security review of the core on-chain engine flagged issues we're fixing now — nothing goes live on the main network until those pass every check.

7/ Steady, unglamorous, compounding work: find it, fix it, test it so it can't come back.
